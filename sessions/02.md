during_class: |
  In this class, we will work through Episodes 7–9 of the Software Carpentry Git lesson to learn how to use version control while developing code. These lessons are where Git can become tricky to navigate, so we will work with peers and the instructor to get more experience and support as we learn the ropes.

  **Learning goals:** By the end of class, you should be able to:
    - Explain the importance and benefits of using version control in any project.
    - Set up and configure Git on your local machine.
    - Create and manage Git repositories, tracking changes effectively.
    - Collaborate with others by pushing and pulling changes from remote repositories.
    - Resolve common conflicts that arise during collaborative work.
    - Understand how to use GitHub for collaborative software development and general project management.
