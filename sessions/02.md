In this class, will work through the Software Carpentry (SWC) git lesson to learn about and how to use version control while developing code.

Learning Goals:
* Practice cloning repositories
* Learn to use add, commit, push, and pull. 
* Work with branches, merge conflicts, and pull requests.
* Establish a team repository workflow.
* Explore the role of version control and GitHub in open-source software development.

## Before Coming to Class
* Work through the Summary \& Setup for the [SWC git lesson](https://swcarpentry.github.io/git-novice/index.html).
* Work through Episodes [1](https://swcarpentry.github.io/git-novice/01-basics.html) - [6](https://swcarpentry.github.io/git-novice/06-ignore.html) (inclusive). 

Time Estimate: If you are new to git, these lessons will likely take you about 1.5 hours to work through.
Students with more experiene may find it goes faster.

## In Class
In class, we will work through Episodes 7 - 9 as a group. These lessons are where git can get quite tricky to navigate, so having support can be really helpful as you learn the ropes.

## After Class: 
* [Complete lesson 10](https://swcarpentry.github.io/git-novice/10-open.html) to learn about the role of version control in open science.
+ perhaps a tiny reflection
This will likely take you about 10–20 min
